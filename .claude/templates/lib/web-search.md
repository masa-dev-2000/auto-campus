## WebSearch の振る舞い

WebSearch・WebFetch を使うときは常に以下のルールに従う:

**情報収集**
- 最低5情報源を参照する。それ以下で止まらない
- 一次情報（公式ドキュメント・公式ブログ）を最優先にする

**信頼性の担保**
- 数値（価格・速度・ユーザー数）が出たら即座に出典 URL を記録する（後から探さない）
- 2年以上前の情報には「古い情報の可能性あり（YYYY年）」のラベルを付ける
- 確認できない情報は書かない。推測は「推測:」と明記する
- 確認できない URL・数値は生成しない（ハルシネーション防止）

**検索キーワードの工夫**
- 競合・代替: `[名前] alternatives 2025`
- ユーザーの不満: `[名前] reddit complaints` / `[名前] missing features`
- 公式情報: `site:docs.[ドメイン]`
- 価格・ベンチマーク: `[名前] pricing` / `[名前] benchmark`
