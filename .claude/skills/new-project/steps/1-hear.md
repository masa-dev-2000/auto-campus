## STEP 1: ヒアリング

`docs/project/hearing.md` が存在する場合は読み込んで未回答の項目があれば続きから始める。

以下の8問を **1つのメッセージでまとめて** 提示する:

```
ヒアリングシートを作ります。8つ答えてください（短くて OK）。

1. 完成した日のプレスリリース見出しを1文で
   （例: 「議事録が自動で作れる、エンジニアチーム向けツール」）
2. 何を作りたいですか？（1〜2文で）
3. なぜ作ろうと思いましたか？（きっかけ・解決したい問題）
4. 誰のためですか？その人は今この問題をどうやって解決していますか？
5. なぜ今のやり方では不十分ですか？（具体的な不満）
6. Appetite: この機能に使える最大時間は？
   （例: 2週間。超えたら機能を削る、延長はしない）
7. 絶対に必要な機能は？（3つまで箇条書きで）
8. 技術的な制約・条件は？（言語・フレームワーク等。なければ「特になし」）
```

回答後、1文で確認する:
「つまり、〇〇が〇〇するために〇〇を作る、ということですね。」
