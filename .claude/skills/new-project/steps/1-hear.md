## STEP 1: ヒアリング

`docs/project/STATE.md` が存在する場合は読み込んで未回答の質問があれば続きから始める。

以下の5問を **1つのメッセージでまとめて** 提示する:

```
以下の5問に答えてください:

1. 何を作りたいですか？（1〜2文で）
2. 誰のためですか？（具体的な1人を想像して）
3. そのユーザーは今、同じ問題をどう解決していますか？（現在の代替手段）
4. なぜ今の解決策では不十分なのですか？
5. このプロダクトが「成功した」と言えるのはどんな状態ですか？
```

回答後、1文で確認する:
「つまり、〇〇が〇〇するために〇〇を作る、ということですね。」
