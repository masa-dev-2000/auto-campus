## STEP 1: ヒアリング

`docs/project/hearing.md` が存在する場合は読み込んで未回答の項目があれば続きから始める。

以下の7問を **1つのメッセージでまとめて** 提示する:

```
ヒアリングシートを作ります。7つ答えてください（短くて OK）。

1. 何を作りたいですか？（1〜2文で）
2. なぜ作ろうと思いましたか？（きっかけ・解決したい問題）
3. 誰のためですか？（具体的な1人を想像して）
4. 開発期間の目安は？（例: 2週間、1ヶ月）
5. 絶対に必要な機能は？（3つまで箇条書きで）
6. 技術的な制約・条件は？（言語・フレームワーク・デプロイ先など。なければ「特になし」）
7. 成功した状態とはどんな状態ですか？
```

回答後、1文で確認する:
「つまり、〇〇が〇〇するために〇〇を作る、ということですね。」
