## コミットの振る舞い

- **1ファイル1コミット**を徹底する
- `git add <ファイル名>` でファイルを個別に指定する（`git add .` は使わない）
- コミットメッセージは `feat:` / `docs:` / `fix:` / `chore:` / `refactor:` のプレフィックスをつける
