## STEP 3: フェーズ計画生成

`docs/project/phases.md` を生成する。

**ルール:**
- Phase 0 は「核心技術が動くことの最小確認」だけに絞る
- フロントエンドや API は Phase 0 には含めない
- 完了条件は数値で測れる1文で書く

```markdown
# フェーズ・タスク一覧

## 現在のフェーズ
**Phase 0（PoC）** — 未着手

---

## Phase 0 — [核心技術の動作確認]

**完了条件**: [数値で測れる1文]

### Step 0-1: 環境構築
- [ ] 必要ツールのインストール（バージョン明記）
- [ ] `.env.example` 作成
- [ ] `.gitignore` 確認

### Step 0-2: [最小機能の実装]
- [ ] ...

---

## Phase 1 — [コア機能実装]

**前提**: Phase 0 完了
**完了条件**: [P0 機能がすべて動く状態]
```
