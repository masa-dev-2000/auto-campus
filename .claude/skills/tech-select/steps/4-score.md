### 加重スコアリング

STEP 1 で聞いた「重視する条件」をもとに評価軸と重みを設定（合計100）し、各候補を1〜5で採点する。

```markdown
| 評価軸 | 重み | [A] | [B] | [C] |
|--------|------|-----|-----|-----|
| ...    | ...  | ... | ... | ... |
| **加重合計** | 100 | | | |
```

### バイアスチェック

- **可用性バイアス**: 最近使ったことがある技術を過大評価していないか
- **権威バイアス**: 「大手が使っているから」を理由にしていないか
- **確証バイアス**: 最初から決めていた答えに有利な観点だけ選んでいないか
- **引用の不均衡**: 採用候補だけ詳細なソースになっていないか

バイアスが検出された場合は該当の評価軸を見直してから推奨を出す。
