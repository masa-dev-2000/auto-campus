# プロジェクト概要・要件定義

## プロダクトの一言説明

会議をリアルタイムでサポートするAIシステム。
文字起こし・情報整理・リサーチ・情報補強をモード別に提供する。

---

## ゴール（オーナー視点）

1. Claude Code のノウハウを実践しながら習得する
2. 開発プロジェクトの進め方を体で覚える
3. 実際に使えるツールを作る

---

## コア機能

| # | 機能 | 概要 | 差別化度 |
|---|---|---|---|
| 1 | リアルタイム文字起こし | 発言者ラベル付きでリアルタイム表示 | 低（競合多数） |
| 2 | 視覚的情報整理 | 会話ログをマインドマップ・要件リスト等に変換 | 高 |
| 3 | 手動リサーチ | ホットキーで会話文脈を元にリサーチ実行 | 最高（競合なし） |
| 4 | 自動情報補強 | 誤情報・古い情報に「最新では〜」と優しく添える | 最高（競合なし） |

---

## モード設計

モードによって、聴く観点・視覚化の形・補強の積極度が変わる。

| モード | 視覚化の形 | 補強の積極度 | リサーチ |
|---|---|---|---|
| フリー議論 | マインドマップ（発散型） | 控えめ | 手動のみ |
| 要件ヒアリング | 構造化リスト・優先度付き | 積極的 | 自動＋手動 |
| インタビュー | Q&Aカード形式 | ほぼ無効 | 手動のみ |
| ブレスト | アイデアクラスタリング | 無効 | 手動のみ |

モードは開始時に選択し、途中で切り替え可能。

---

## 自動補強のUX設計

否定から入らず、方向修正する形。

```
レベル1（さりげなく）
「📌 補足: 2024年のデータでは〇〇億円規模」
→ 発言を止めない、横にそっと出す

レベル2（注目を促す）
「⚠️ 最新情報: その規制は2025年改正で変更されています」
→ 重要度高め、クリックで詳細

レベル3（手動トリガー）
人間が「これ調べて」と指示したとき
→ フル検索結果をパネルで展開
```

発火条件・閾値は Phase 2 で詰める。

## 競合分析サマリー

### 直接競合なし

現在市場に、このプロダクトの全機能を備えたツールは存在しない。

| ツール | 得意 | 欠けていること |
|---|---|---|
| Otter / Fireflies | 文字起こし・事後まとめ | ライブ中のAI支援なし |
| Hedy AI（最有力競合） | リアルタイム会話コーチング | 外部リサーチ・情報補強なし |
| Microsoft Copilot | Teams内統合 | Teams外不可、リサーチ機能なし |
| MeetGeek | 会議種別自動検出（事後） | ライブでモード切替不可 |

### 差別化ポイント
- 人間がトリガーするリアルタイムリサーチ → 市場に存在しない
- 「最新情報では〜」スタイルの情報補強 → 市場に存在しない
- ライブ会話からの視覚的情報整理 → 市場に存在しない
- ライブ中のモード切替 → 市場に存在しない

## 技術スタック選定

### 採用

| 役割 | 技術 | 選定理由 |
|---|---|---|
| STT | Deepgram Nova-3 | レイテンシ最小（<300ms）、話者分離、WebSocketネイティブ |
| VAD | Silero VAD | デファクトスタンダード、<1ms/チャンク |
| LLM（即時） | Claude Haiku 4.5 | 250ms〜、補正・即時提案向け |
| LLM（リサーチ） | Claude Sonnet 4.6 | 品質優先、視覚化整理向け |
| リサーチ | Perplexity API | 出典付き検索、500ms以内 |
| バックエンド | Python / FastAPI | STT/LLM 連携の実績多数 |
| フロントエンド | React / Next.js | エコシステムの豊富さ |
| 音声キャプチャ | Electron | 対面・オンライン両対応（ブラウザは不可） |

### 代替案（検討済み）

| 役割 | 代替案 | 不採用理由 |
|---|---|---|
| STT | Whisper（自前） | リアルタイムに不向き、エンジニアリングコスト大 |
| STT | AssemblyAI | Deepgramより若干遅い |
| LLM（即時） | Gemini Flash | Haiku と同等だが Anthropic API で統一したい |
| バックエンド | Node.js | Python の方が AI/ML ライブラリが豊富 |

## リスク

| リスク | 内容 | 対策 |
|---|---|---|
| 音声キャプチャの複雑さ | ブラウザは不可、Electron必須 | Phase 0 はマイクのみで始める |
| 自動補強のノイズ | 出すぎると邪魔 | 抑制寄りのチューニングから始める |
| 長時間会議のコンテキスト | 60分 ≈ 12万トークン | 10分ごとに階層サマリー圧縮 |
| STT の話者混同 | クロストークで誤帰属 | Deepgram の話者分離に頼り過信しない |
