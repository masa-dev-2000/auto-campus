## Phase 0 — 音声 → テキスト → 画面表示の PoC

**目的**: 核心技術が動くことを最小構成で確認する

**完了条件**: マイクで話した内容が 1.5 秒以内に画面に表示される

### Step 0-1: 環境構築

依存関係なし。最初にやる。

- [ ] `.env.example` 作成（必要な API キーの一覧）
- [ ] `.gitignore` 作成（`.env` / `__pycache__` / `node_modules` 等）
- [ ] Python 環境初期化（`uv init` or `python -m venv`）
- [ ] `requirements.txt` or `pyproject.toml` 作成
- [ ] Deepgram アカウント作成・API キー取得 → `.env` に記載
- [ ] Node.js / npm 環境確認

### Step 0-2: 音声キャプチャ確認（バックエンド単体）

Step 0-1 完了後。フロントエンドは不要。

- [ ] `sounddevice` or `pyaudio` でマイク入力をターミナルに波形表示
- [ ] Silero VAD 統合 → 無音と発話を分離できることを確認
- [ ] **完了条件**: 話したときだけコンソールに「発話検出」と出る

### Step 0-3: STT 接続確認（バックエンド単体）

Step 0-2 完了後。

- [ ] Deepgram Nova-3 WebSocket クライアント実装
- [ ] VAD で検出した音声チャンクを Deepgram に送信
- [ ] 文字起こし結果をターミナルに出力
- [ ] **完了条件**: 話した内容がコンソールにリアルタイムで出る

### Step 0-4: バックエンド API 構築

Step 0-3 完了後。

- [ ] FastAPI プロジェクト初期化（`src/` 構成）
- [ ] WebSocket エンドポイント実装（`/ws/transcript`）
- [ ] 文字起こし結果を WebSocket 経由で配信
- [ ] **完了条件**: `wscat` 等で接続してテキストが流れる

### Step 0-5: フロントエンド最小 UI

Step 0-4 完了後。

- [ ] React プロジェクト初期化（Vite）
- [ ] バックエンド WebSocket への接続
- [ ] リアルタイムテキスト表示コンポーネント
- [ ] **完了条件**: ブラウザ上でリアルタイム文字起こしが表示される

### Step 0-6: 統合確認・計測

Step 0-5 完了後。

- [ ] エンドツーエンドのレイテンシ計測（発話 → 画面表示）
- [ ] 1.5 秒以内に表示されることを確認
- [ ] CLAUDE.md の「コマンド」セクションに起動コマンドを追記
- [ ] **完了条件**: Phase 0 の完了条件を満たす

## Phase 2 — 自動補強・視覚化高度化

**前提**: Phase 1 完了

**完了条件**: 誤った情報・古い情報に「最新では〜」と優しく補強が出る

### Step 2-1: 発話完了検知の精度向上

- [ ] VAD エンドポイント（発話終了）の検知チューニング
- [ ] 文の区切りを意味的に検知（句点・間・イントネーション）

### Step 2-2: ファクトチェック判定

Step 2-1 完了後。

- [ ] 発話ごとに「補強すべきか」を LLM で判定（Haiku）

- [ ] **完了条件**: 明らかな数字・固有名詞のみに反応する

### Step 2-3: 補強カード UI

Step 2-2 完了後。

- [ ] レベル1（さりげなく）/ レベル2（注目）/ レベル3（手動）の表示制御
- [ ] 「否定せず添える」UX の実装
- [ ] **完了条件**: 補強が出ても会話の流れを妨げない

### Step 2-4: モード別視覚化高度化

Step 1-5 完了後（Step 2-2 と並行可）。
